# 🎙️ 더빙 연습실

브라우저에서 바로 쓰는 더빙 연습 앱이에요. 설치는 필요 없어요.
MP4 영상에 대사 구간을 찍고 캐릭터를 나눈 뒤 구간별로 녹음하면, 내 목소리가 입혀진 영상을 만들 수 있어요.

**👉 바로 쓰기: https://halftomatodev.github.io/dub_practice/**

## 준비물
- **크롬 또는 엣지(PC/맥).** 사파리와 파이어폭스는 폴더 저장 기능을 지원하지 않아요.
- **헤드폰.** 녹음할 때 영상 소리가 마이크로 들어가지 않게 해줘요.
- **마이크.** 오디오 인터페이스나 USB 마이크를 쓸 수 있어요.
- **저장할 폴더.** 드롭박스 폴더를 고르면 녹음이 자동으로 동기화돼요.

## 사용 순서
1. **저장 폴더 선택**을 누르고 드롭박스 안의 폴더를 고릅니다. 한 번만 하면 돼요.
2. **영상 열기**를 누르거나 MP4를 화면에 끌어다 놓습니다.
3. 오른쪽에서 마이크와 **입력 채널**(인터페이스에서 마이크가 꽂힌 번호)을 고르고 **연결**을 누릅니다.
4. 영상을 재생하면서 대사가 시작될 때 `I`, 끝날 때 `O`를 누르면 구간이 만들어져요.
   - 숫자키 `1`~`9`로 선택한 대사를 캐릭터에 할당합니다.
   - 타임라인에서 구간 양끝을 끌어 길이를 다듬을 수 있어요.
5. `←` `→`로 대사 사이를 이동하며 녹음합니다.

## 기본 단축키
모든 단축키는 ⚙︎ 설정에서 바꿀 수 있어요.

| 키 | 기능 |
|---|---|
| `Space` | 재생 / 일시정지 |
| `Shift+Q` / `Shift+W` | 원본 버전 / 더빙 버전으로 전체 재생 |
| `D` | 원본 ↔ 더빙 전환 |
| `←` `→` | 이전 / 다음 대사 |
| `I` / `O` | 대사 시작 / 끝 찍기 |
| `R` | 녹음 · 재녹음 |
| `Q` / `W` | 현재 대사 원본 듣기 / 내 녹음 듣기 |
| `Esc` | 정지 · 녹음 취소 |
| `J` `L` / `,` `.` | 1초 / 한 프레임 이동 |
| `1`~`9` | 캐릭터 할당 |
| `⌘S` / `Ctrl+S` | 저장 |

## 저장되는 파일
고른 저장 폴더 안에 영상 이름으로 된 폴더가 만들어져요.

```
저장 폴더/
└─ 영상이름/
   ├─ project.json        ← 마커·캐릭터 정보 (같은 영상을 열면 이어서 작업)
   ├─ takes/              ← 대사별 녹음 (캐릭터명_시간.mp3)
   └─ exports/            ← 내 목소리가 입혀진 전체 영상 (.mp4)
```

- **영상 파일:** 폴더로 복사되지 않아요.
- **녹음 파일:** 각자 컴퓨터에만 저장되고, 어디에도 업로드되지 않아요.

## 처음 쓸 때 팁
- **녹음 지연 보정:** 내 녹음이 영상보다 늦게 들리면 ⚙︎ 설정에서 **녹음 지연 보정** 값을 올리세요. 인터페이스마다 한 번만 맞추면 됩니다.
- **프리롤:** 대사 몇 초 전부터 영상을 틀어 타이밍을 잡게 해줘요. 기본값은 2초예요.
- **영상 내보내기 시간:** 영상 길이만큼 실시간으로 재생하면서 녹화해요. 그동안 창을 가리지 마세요.
- **원본 음량:** 원본에서 대사만 지울 수는 없어서, 내 녹음이 있는 구간은 원본 전체의 볼륨을 줄여요. 줄이는 정도는 설정에서 정할 수 있어요.
